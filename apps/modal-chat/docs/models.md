# 채팅 모델 비교

이 문서는 `modal-chat`에서 **현재 사용하는 모델**, **이전에 사용한 모델**, 그리고 비교 대상으로 볼 만한 범용 모델 세 가지를 정리합니다. 수치는 2026-11-05에 확인한 각 제작사의 모델 카드 기준입니다. 비교 모델은 이 앱에서 실행하거나 성능을 측정한 모델이 아닙니다.

## 용어

- **B**는 파라미터 10억 개를 뜻합니다. 파라미터가 많으면 모델 가중치를 저장하고 로드하는 데 필요한 메모리도 대체로 늘어납니다. 파라미터 수만으로 답변 품질을 판단할 수는 없습니다.
- **문맥 길이**는 한 요청에서 모델이 다룰 수 있는 입력과 출력의 토큰 수에 관한 모델 한도입니다. 토큰은 단어와 일대일로 대응하지 않습니다.
- **FP16 가중치 추정치**는 `파라미터 수 × 2바이트`로 계산한 대략적인 크기입니다. 실제 GPU 메모리는 생성 중간값과 KV 캐시 등 때문에 더 필요하며, 다운로드 파일 크기와도 다를 수 있습니다.

## 주요 스펙

| 구분 | 모델 | 파라미터 | 모델 문맥 길이 | 입력 → 출력 | FP16 가중치 추정치 | 라이선스 |
| --- | --- | ---: | ---: | --- | ---: | --- |
| 현재 | [Qwen3-0.6B](https://huggingface.co/Qwen/Qwen3-0.6B) | 0.6B | 32,768 토큰 | 텍스트 → 텍스트 | 약 1.2 GB | Apache-2.0 |
| 이전 | [Qwen3-1.7B](https://huggingface.co/Qwen/Qwen3-1.7B) | 1.7B | 32,768 토큰 | 텍스트 → 텍스트 | 약 3.4 GB | Apache-2.0 |
| 비교 | [Qwen3-4B](https://huggingface.co/Qwen/Qwen3-4B) | 4.0B | 기본 32,768 토큰 | 텍스트 → 텍스트 | 약 8 GB | Apache-2.0 |
| 비교 | [Llama 3.1 8B Instruct](https://huggingface.co/meta-llama/Llama-3.1-8B-Instruct) | 8B | 128K 토큰 | 텍스트 → 텍스트 | 약 16 GB | Llama 3.1 Community License |
| 비교 | [Gemma 3 4B IT](https://huggingface.co/google/gemma-3-4b-it) | 4B급 | 128K 토큰 | 텍스트·이미지 → 텍스트 | 약 8 GB | Gemma 이용 약관 |

Qwen3-4B는 별도 **YaRN 설정**을 적용하면 모델 카드에 최대 131,072토큰이 제시되어 있습니다. 표에는 기본 문맥 길이를 적었습니다. Llama와 Gemma의 `128K`는 각 모델 카드의 표기를 따랐습니다.

## 선택할 때 볼 점

- **Qwen3-0.6B**: 현재 앱의 빠른 실험용 모델입니다. 작은 가중치 덕분에 로드 부담이 낮지만, 복잡한 질문에서는 더 큰 모델과 답변을 비교해 보는 것이 좋습니다. Qwen3 계열은 제작사 모델 카드에서 100개 이상의 언어와 방언을 지원한다고 설명합니다.
- **Qwen3-1.7B**: 이 앱의 이전 모델입니다. 0.6B와 같은 문맥 길이와 Qwen 채팅 형식을 사용하면서 모델 크기는 더 큽니다. 모델을 바꾸면 첫 실행에서 해당 가중치를 새로 내려받아야 합니다.
- **Qwen3-4B**: 같은 계열에서 크기를 올려 볼 때 비교하기 쉽습니다. 더 많은 가중치와 GPU 메모리가 필요하므로 현재의 경량화 목표와는 거리가 있습니다.
- **Llama 3.1 8B Instruct**: 텍스트 채팅 비교 모델입니다. 제작사가 공식 지원 언어로 열거한 8개 언어에 한국어는 포함되지 않습니다. Hugging Face에서 가중치를 받으려면 [Meta의 이용 조건에 동의](https://huggingface.co/meta-llama/Llama-3.1-8B-Instruct)해야 합니다.
- **Gemma 3 4B IT**: 텍스트뿐 아니라 이미지를 입력할 수 있는 비교 모델입니다. 제작사 모델 카드는 140개 이상의 언어를 언급합니다. Hugging Face에서 가중치를 받으려면 [Google의 이용 조건에 동의](https://huggingface.co/google/gemma-3-4b-it)해야 합니다.

## 이 앱과 연결해서 이해하기

현재 [`app.py`](../src/modal_chat/app.py)는 `Qwen/Qwen3-0.6B`를 `float16`으로 로드하고, 답변을 최대 **256개의 새 토큰**으로 제한합니다. 질문마다 이전 대화를 보내지 않으므로 모델의 32,768토큰 문맥 길이를 대화 기록에 활용하지는 않습니다. `gpu="any"`는 Modal이 사용 가능한 GPU를 고르게 하는 설정입니다.

모델을 바꿀 때는 이름만 바꾸면 끝나는지 먼저 확인해야 합니다. 특히 Gemma 3는 이미지 입력을 위한 파이프라인과 메시지 형식이 필요하고, Llama 3.1과 Gemma 3는 가중치 접근 조건이 있습니다. 표의 FP16 추정치도 **실제 필요한 GPU 메모리의 상한이나 권장 사양이 아닙니다**.
